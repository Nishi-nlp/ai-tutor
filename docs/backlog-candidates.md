# AI Tutor 7日版 Issue Backlog

## 運用方針

- 対象は`la.linear_combination`の縦切りだけとする。
- Issue IDには`-7D`を付け、旧MVP Issueと区別する。
- 1 Issueは半日以内を目安にし、同じ成果物を変更する作業はまとめる。
- 必須、Stretch、対象外を混在させない。
- 完了はコード作成ではなく、記載した受け入れ条件の確認で判断する。

```mermaid

```
