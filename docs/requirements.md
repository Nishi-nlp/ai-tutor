# AI Tutor 7日版 要件定義

## 1. 目的

7日版は`la.linear_combination`だけを対象に、次の学習フローをローカルで
デモ可能にする技術検証である。

```text
教材登録
→ チャンク・Embedding生成
→ レッスン表示
→ 教材根拠付きAI質問
→ 問題・ヒント
→ 採点
→ Mastery更新
→ 学習履歴の保存
```

教材へ質問できるだけのRAGチャットではなく、KC、レッスン、演習、評価、
学習状態を同じ画面とデータモデルで接続することを価値とする。

## 2. 対象ユーザーと利用条件

- 線形代数を学び直したい単一ユーザー
- ローカル環境での個人利用
- デモ教材は再配布可能なCC0サンプルPDF
- 認証、課金、組織管理、クラウド公開は対象外

## 3. 機能要件

### 3.1 KCとレッスン

- `la.linear_combination`の名称、説明、学習目標、前提KCをYAMLで定義する。
- YAMLの必須項目と存在しない前提KCを検証する。
- KCを再実行可能な処理でDBへ登録し、詳細APIから取得する。
- 説明、具体例、確認問題を含むレッスンを1つ提供する。

### 3.2 問題、ヒント、採点

- 固定回答または数値問題を2問提供する。
- 各問題に3段階以上のヒントを用意し、最大使用レベルを保存する。
- 回答を決定的なロジックで採点し、正誤と理由を返す。
- 回答、評価、ヒント、時刻、Mastery更新根拠をAttemptとして保存する。

### 3.3 Mastery

- KCごとに0〜1のMastery Scoreを保持する。
- 回答評価とヒント使用量から`evidence`を計算する。
- `docs/mastery-policy.md` Version 1の式で更新する。
- 更新前後の値と次の推奨行動を画面に表示する。
- 再読み込み後も最新値を復元する。

### 3.4 教材登録と検索

- PDF、MIMEタイプ、サイズを最低限検証して登録する。
- PDFは公開ディレクトリ外へランダムな保存名で置く。
- ファイル名、サイズ、チェックサムをDBへ保存する。
- CC0教材をページ単位で抽出し、線形結合のチャンクを作る。
- チャンクへ教材名、ページ番号、KC ID、Embeddingモデル名を記録する。
- 質問Embeddingとの類似度で関連チャンクを検索する。
- 検索結果には教材名、ページ番号、チャンクIDを含める。

### 3.5 AIチューター

- LLMとEmbeddingはFastAPIからのみ呼び出す。
- 検索チャンクを根拠に回答し、参照した教材名とページ番号を返す。
- 「教材に記載」「教材から導出」「AI補足」を区別する。
- 関連度が閾値未満なら、教材根拠のある回答を生成せず根拠不足を返す。
- 構造化出力をPydanticで検証し、障害時は安全なエラーを返す。

### 3.6 学習画面

- `app/learn/[kcId]/page.tsx`に一画面の学習フローを実装する。
- 初期表示はServer Component、操作部分はClient Componentとする。
- 学習目標、前提知識、説明、例、問題、ヒント、AI質問、Masteryを表示する。
- ローディング、通信失敗、空状態、根拠不足を明示する。
- デスクトップとスマートフォン幅で主要操作ができる。

## 4. 非機能要件

- APIキーをHTML、ブラウザ向けJavaScript、ログへ出さない。
- LLMへ送る教材チャンクを回答に必要な最小範囲に限定する。
- PDF以外とサイズ上限超過を拒否し、元ファイル名を保存パスに使わない。
- 教材中の命令を信頼せず、代表的なプロンプトインジェクションを試験する。
- 教材の長文を回答へそのまま転載しない。
- 主要バックエンドテスト、lint、Next.js本番ビルドを再現可能にする。

## 5. 受け入れ条件

- 教材登録から履歴保存までの縦切りを1つのデモで確認できる。
- 出典から教材名とページ番号を追跡できる。
- 根拠不足時に回答を捏造しない。
- 問題、ヒント、採点、Mastery更新が接続されている。
- 再読み込み後も学習状態が保持される。
- READMEの手順で新しいローカル環境を起動できる。

## 6. 7日版の対象外

複数KC、OCR、画像・数式のマルチモーダル解析、高度なチャンク化、
ハイブリッド検索、再ランキング、PDFビューアー、会話履歴、Socratic Mode、
Explain-back、復習日計算、Python演習、認証、複数ユーザー、クラウド公開、
本番運用水準の監査と負荷試験は行わない。
